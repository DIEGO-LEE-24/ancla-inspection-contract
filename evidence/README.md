# 근거 기준

구현 근거는 [inspection.py](../examples/inspection-contract/inspection.py), [18개 계약 테스트](../examples/inspection-contract/test_inspection.py), [분리 후 실행 기록](test-results.md)입니다.

구현·테스트·데모는 통합 예제에서 바이트 변경 없이 옮겼습니다. 분리 후 실행 기록은 당시의 파일 해시로 실행 버전을 식별합니다. 문서와 정적 점검의 허용 목록만 새 범위에 맞췄습니다.

예제는 문자열 Decimal·immutable 판정·분리된 설명 계약·과거 기록 조회를 합성 입력으로 검증합니다. 원본 ANCLA의 모델·DB·CI·시연 결과나 지원자의 원본 독립 구현을 증명하지 않습니다.

원본 팀 자료·실제 검증 집계·개인 책임은 공개 허용과 사실관계를 별도로 확인합니다. [파일·링크 점검](../tools/check_repository.py)은 권리·제품 품질 검토를 대신하지 않습니다.
